# Contributing to the PLS website

Thank you for helping. Open an issue to discuss major content or structure changes. For a small correction, create a branch, edit `build.mjs` (text and links), `assets/style.css` (design) or `assets/site.js` (behavior), and open a pull request.

Run `npm run build` and `npm test` before submitting. Include a brief summary and screenshots for visual edits. Do not commit secrets, export files containing subscriber emails, or copied material without permission. The maintainers review changes before merging.
